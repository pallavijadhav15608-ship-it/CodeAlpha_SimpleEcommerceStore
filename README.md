# CodeAlpha_SimpleEcommerceStore

A full-stack e-commerce project for the CodeAlpha Full Stack Development Internship — Task 1.

## Features

- Product listing
- Shopping cart
- User registration
- User login
- Password hashing with bcryptjs
- Order processing
- SQLite database
- Responsive HTML/CSS/JavaScript frontend
- Express.js backend REST API

## Technologies

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- SQLite
- better-sqlite3
- bcryptjs

## How to run

1. Install Node.js LTS.
2. Open Command Prompt or Git Bash inside this folder.
3. Run:

```bash
npm install
npm start
```

4. Open:

```text
http://localhost:3000
```

## Suggested testing

1. Register a new account.
2. Login.
3. Add 2–3 products to the cart.
4. Change quantities.
5. Place an order.
6. Refresh the page.
7. Login again and verify the order history.
